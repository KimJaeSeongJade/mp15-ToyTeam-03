### 진행 상황 

> P0 단계 구현을 위한 각자의 담당 작업 개발 진행 중

- 김재준 (팀장) - Player

1. 이동 완료
2. 설치 모드 구현중
3. 공격모드 개발 예정


- 조영래 (PM) - Game Manager

1. 작업에 필요한 GroundRule, Convention 문서 3종 문서 작업 완료 
2. 게임 매니저, 웨이브 매니져 개발중
2-1. 게임 매니저 : 현재 상태 관리 구현중
2-2. 웨이브 매니저 : 웨이브 시작-종료 완료, 기능 연결 대기중
3. 게임 매니저, 웨이브 매니저 구현 예정

- 강예찬 - Turret

1. 기본 터렛 개발중
2. 터렛 타입 호출 반환 구현중


- 한장수 - Map

1. 경로, 스폰 완료
2. 골인 진행중
3. 터렛 설치 지점 예정


- 유희찬 - Monster

1. 몬스터 이동 구현완료, 확인 필요
2. 데미지 사망처리, 성 내구도 감소 구현 예정
3. IDamageable 인터페이스 구현 TakeDamage(float) 로 대미지 처리


## 막힌(버그 발생한) 부분

업무 보고 첫 회의로 팀원 간 확인 사항이 없음.
