## 오늘 진행한 업무

개발 명세표 기준 토의 진행

P0 → P1 → P2 순으로 개발을 진행한다. 

P0 단계는 프로토타입에서도 가장 최소단위로 구현하는 것으로 10월 4일(일)까지 구현을 완료하는 것이 목표이다.
P1 단계는 기획단계에서 구상한 수준의 구현을 목표로 한다. 
P2 단계는 추가 확장하는 부분과 연출, 밸런스 조정을 중심으로 진행한다.

각 단계별 구현 내용은 개발 명세서에서 확인할 수 있다.

Game Manager, Monster, Map 간의 상호작용을 통해 타워디펜스의 몬스터 웨이브 플로우를 정리하였다.
웨이브 시작/몬스터 스폰/웨이브 종료 처리 순으로 서로간에 받는 정보 정리

추후에 모르는 부분이 있는 경우 팀장에게 질문하여 해결한다.

## 막힌(버그 발생한) 부분

기본 공격 터렛을 포함한 4개의 터렛 기준이 모호함.
기획 단계에서 터렛 4종을 공격/수비/버프/골드 로 설정하였는데 
수비 터렛의 역할과 구현이 명확하지 않다고 생각하여 논의 진행.
(수비 터렛이 터렛 깔리는 위치에 존재했을 때 어떻게 처리할지)


## 해결방안

토의를 통해 P1 단계의 기획에서 터렛 4종 기준 임시 확정. 
추후 구현과정에서 수정이 필요한 경우 수정 예정

기본 공격 터렛 : 일반 공격 터렛, 범위 내에 몬스터가 감지되면 공격한다.

감속 터렛 : 몬스터 이동속도 감속 터렛, 범위 내에 몬스터가 감지되면 몬스터의 이동속도를 낮춘다.

버프 터렛 : 버프 터렛은 공격을 하지 않고, 버프 범위 내의 터렛의 공격력, 공격 속도를 강화한다.

골드 터렛 : 골드 터렛은 공격을 하지 않고, 일정 쿨타임마다 골드를 드랍한다.
