## 오늘 진행한 업무


### 구글 시트 업무 일지에 개별 업무 작성
개인이 담당한 기능별 업무 작성 완료
추후에 추가로 필요한 기능이 있는 경우 행을 추가하여 기능 추가할 것


### 데일리 체크인 작성 규칙 
매일 오후 5시에 반드시 작성할 것\
작업을 진행한다면 반드시 평일 휴일 구분 없이 체크인 작성할 것

### Issue를 활용한 칸반보드 연동 방식의 협업 방식 안내
목요일 이전까지 `Github 협업 방식 안내자료` 문서화 예정\
팀 전원에게 작성 방식 안내하였음\
추가로 확인이 필요한 경우 해당 문서 참고

### PR 작성 방법 안내

프로젝트 시작(목요일)한 날부터 `최소 하루에 PR 1번`은 진행해야함.

PR 작성 방법 또한 교본을 기준으로 작성한다는 것을 안내하였으나\
`컨벤션 문서`에 문서화하여 Github/Notion 페이지에 게시/업데이트 예정



### 회의 일정

회의는 기본적으로 수업날 기준으로 오전 회의와 오후 회의로 2번 회의가 진행됩니다.

### 오전 회의 (전날 진행한 작업 정리)
회의는 매일 2교시 시작할 때 진행합니다. \
10시부터 진행(`10:00 ~ 10:30`) \
1교시에 본인이 전날에 작업한 내용 정리 및 회의 준비합니다.

> ### 오전 회의 내용 
>본인이 전 날에 진행한 작업 / 막혔던 작업 내용 / 오늘 해야 할 작업 내용\
>토의를 통해 보완 후 작업 진행

### 오후 회의 (체크인 전 오늘의 회고)

데일리 체크인 `17:00` 이전에 가볍게 `10분~30분` 정도 회의 진행 예정

> ### 오후 회의 내용
> 오늘 진행한 작업 (완료한 작업, 미비된 작업) 간단하게 팀원들에게 전달 이후 팀원 전체 데일리 체크인 작성
