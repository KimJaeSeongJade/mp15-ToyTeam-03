# 튜토리얼 씬

`Assets/Scenes/Main Scenes/TutorialScene.unity`는 BigIsland 1의 별도 복제본이다.
본게임 씬/원본 프리팹에는 튜토리얼 컴포넌트를 추가하지 않는다.

## 진행

W → A → S → D 각각 연속 1초 유지 → Shift/Space 텍스트 소개 → 실제 일반 공격 발사체 5발 →
스킬 3회(쿨타임 3초) → 마지막 스킬 오브젝트 종료 확인 → 입력 잠금/1.25초 대기 → 몬스터 등장 컷씬 →
직접 사냥 → 골드 배달을 캐릭터가 보이는 원거리 컷씬으로 관찰 → 1번 공격 터렛 설치 →
일반 몬스터 방어 → 단단한 몬스터를 놓치고 실제 캐슬 HP 10 감소 → 2번 방어를 더해 관통 터렛 조합 →
동일한 단단한 몬스터 처치 → 다른 위치의 몬스터 등장/준비 중 대기 → 별도 기본 터렛 판매 →
새 지점에 2번 방어 설치 → 정보 UI 확인/1번 공격을 더해 거대 터렛 조합 → 실전 웨이브 → 완료 로그.

조작 단계에서는 관련 HUD 이외를 어둡게 처리하고, 안내한 키를 새로 누를 때까지 모든 플레이어 입력을 막는다.
해당 키를 누른 프레임에 잠금을 풀어 실제 조작에도 사용한다. 이동은 현재 요구한 WASD 키,
건설/조합은 단계별 1번 또는 2번, 판매는 우클릭, 건설 종료는 E를 기다린다.
무관한 키와 마우스 이동으로는 해제하지 않는다. 이동 키를 1초 전에 놓으면 해당 유지 시간은 다시 0부터 센다.
골드/터렛/캐슬의 자동 설명은 키 확인을 요구하지 않고 이동/시점도 잠그지 않는다. 컷씬 동안만 입력을 잠근다.
설명 박스는 강조한 UI 위/아래에 배치한다. 줄바꿈을 제거하고 한 줄 폭을 늘리며 작은 화면에서는 글자 크기를 자동 조절한다.
다음 버튼과 준비 시간 제한은 없다. 1~4번 슬롯을 모두 표시하되 건설 시 해당 단계의 1번 또는 2번만 허용한다.
판매는 별도 판매 단계에서만 허용한다. 안내한 빌드포인트 이외에는 건설 레이가 닿지 않게 제한한다.

튜토리얼 조합표는 공격→방어=관통, 방어→공격=거대 두 조합만 사용한다.
초기 잔액은 0G이며 첫 사냥에서 골드 300G를 실제 배달한다. 공격 100G + 관통 조합 200G 지불 후 잔액은 0G다.
판매용 지점에는 별도 제공한 기본 터렛이 있다. 이 연습용 복제본의 구매가는 900G, 실제 판매금은 450G다.
환급 450G로 방어 150G + 거대 조합 300G를 지불하면 다시 0G가 된다. 관통 터렛을 판매하지 않는다.
후속 방어 시연 몬스터는 추가 골드를 주지 않으므로 판매 단계의 0G 상황을 유지한다.
원본 관통 터렛의 0G 가격/누락된 탄환은 튜토리얼 복제본에서만 보완했다. 원본 프리팹의 가격/능력치는 수정하지 않는다.
기본 공격력 10/쿨타임 3초와 관통 공격력 60/쿨타임 0.75초를 비교한다. 단단한 몬스터는 거북이 비주얼, HP 100/방어 25로 동일하게 사용한다.

## 컴포넌트

- TutorialManager: 순서와 단계 완료 조건, ESC 확인, 완료 저장.
- TutorialInputFilter: 튜토리얼 플레이어에만 부착하는 입력 제한.
- TutorialGoldDelivery: WaveManager 없이 기존 GoldDrop의 배달 시작/완료 확인.
- TutorialUI: 기존 GameManager HUD의 공격/스킬/건설/골드를 강조하고 골드/진행 표시를 갱신한다. 추가 UI는 설명/진행/강조/스킵 확인만 사용한다.
- TutorialBuildPointGuide: 건설/판매 지점 및 몬스터의 화살표/거리 표시. 다른 지점으로 바꾸면 바닥 링도 함께 이동한다.
- TutorialBuildAreaFilter: 현재 단계의 빌드포인트만 건설 레이에 포함하고 기존 레이어를 보관/복원한다.
- TutorialEnemyRoute: 튜토리얼에서만 기존 이동 AI를 끄고 NavMesh로 건설 구역을 지나 캐슬에 도달한다. 실제 골인한 몬스터로 CastleTakeDamage를 호출한다.
- TutorialCastleCutscene: 기존 캐슬/골인지점 참조를 유지한다. 현재 흐름은 TutorialSpawnCutscene과 실제 몬스터 골인을 사용하며 별도 연출용 몬스터를 생성하지 않는다.
- TutorialProjectileTargeting: 튜토리얼 총알 복제본에서만 소유 터렛의 사거리 안에 있는 타겟/공격력을 적용한다. 사거리 밖의 대기 몬스터를 먼저 죽이지 않는다. 기존 터렛/총알 코드는 수정하지 않는다.
- TutorialPracticeShot: 비활성 일반 공격 템플릿에만 부착, 풀에서 실제 꺼낸 탄환마다 1회 계산한다. 클릭/누르기 유지 모두 인정하고 풀 생성은 세지 않는다.
- TutorialSpawnCutscene: 등장, 캐릭터/골드 배달, 터렛 방어, 실제 캐슬 도착의 Cinemachine 카메라 구도를 관리하고 기존 카메라/이동/몬스터 이동 상태를 복구한다.

튜토리얼 플레이어 인스턴스의 PlayerAttackMode._skillTime을 3으로 오버라이드한다. 원본 Player 프리팹/PlayerAttackMode.cs는 수정하지 않는다.
TMP는 튜토리얼 씬의 폰트/머티리얼 불일치를 정리하고, TutorialFontSource로 멀티 아틀라스 동적 한글 폰트를 실행 중 생성한다.
튜토리얼 설명/스킵/기존 HUD에만 적용하며 원본 SDF 에셋과 본게임 폰트 설정은 유지한다. 일반 기호는 기본 TMP 폰트로 대체한다.

ESC로 확인창을 열면 게임과 입력이 정지한다. 취소는 원래 단계로 돌아온다.
스킵도 완료로 저장한다. 저장 키는 `Tutorial.Completed.v1`, 조회는 `TutorialManager.HasCompleted`.
완료 시 화면에 클리어 문구를 출력하지 않고 안내를 숨긴 뒤 Debug.Log("이제 튜토리얼 클리어!")를 출력한다.
실전 웨이브는 처치 수를 확인하지 않는다. 사망 또는 골인으로 모든 웨이브 몬스터가 나가면 완료한다.
타이틀/본게임 자동 진입은 보류했으므로 `OnCompleted` UnityEvent만 제공한다.
직접 튜토리얼 씬을 실행하는 개발 검증은 저장 여부와 무관하게 가능하다.
향후 진입 버튼에서 HasCompleted를 검사해야 첫 실행만 안내하는 동작이 완성된다.

## 기존 파일 변경

- PlayerInputReader: 공통 IPlayerInputFilter 연결 및 키 정보 조회만 추가. 필터 없으면 기존 입력 그대로.
- GoldDrop: WaveManager가 없는 씬의 이벤트 구독/해제 null 검사, 파괴 시 구독 해제.

GameManager, WaveManager, BuildPoint, BaseTurret, 개별 터렛/공격 스크립트는 변경하지 않았다.
씬 안의 GameManager는 자동 Start/Update를 끄고 플레이어 참조와 기존 UI 콜백만 재사용한다.
튜토리얼 씬에서 WaveManager 컴포넌트를 제거하고 기존 MonsterSpawner는 비활성화했다.
조합표는 원본 프리팹을 유지하며 복제 씬의 인스펙터 오버라이드로 4슬롯/1조합을 설정했다.

## 확인

씬 생성 도구를 삭제한 상태에서는 기존 TutorialScene을 직접 편집한다.

몬스터는 OutsideSpawnPosition 또는 SecondarySpawnPosition에서 등장한다. 직접 사냥 몬스터는 CombatSpawn까지 접근하고 대기한다.
터렛 시연은 실제 BuildPoint 근처를 지나 CastleCutscene.HitPoint로 이동한다. 골인 시연 몬스터는 실제 캐슬 도착 후 컷씬 중에 피해를 적용한다.
NavMesh 샘플/경로가 완전한지 검사하며, 실패하면 로그와 안내를 표시한다. 플레이어용 TutorialBoundary는 해당 튜토리얼 몬스터와의 충돌만 제외한다.
현재 편집한 주 등장 지점과 주 빌드포인트는 유지한다. 새 등장 지점은 원본 맵의 다른 도로 좌표(-1.83, 3.136, 29.97)를 사용한다.
추가된 TutorialSaleBuildPoint / TutorialSecondaryBuildPoint는 씬에서 직접 위치를 조절할 수 있으며 실행 시 가까운 NavMesh 높이에 맞춘다.

실제 플레이에서는 전체 단계, 골드 300G 배달, 건설/조합 후 잔액, 잠긴 2~4번 입력,
스킵 취소/확정, 캐슬 카메라 복구를 확인한다. 준비 중 오래 기다려도 웨이브가 자동 시작되면 안 된다.
연습 단계에서는 무관한 키로 잠금이 풀리지 않는지, WASD를 각각 1초 유지해야 하는지, 마우스를 누르고 있어도 실제 발사 5발로 넘어가는지 확인한다.
스킬 3회 후 마지막 스킬 종료/1.25초 대기, 골드 카메라에서 설명을 읽은 뒤 배달 시작, 기본 몬스터 처치/단단한 몬스터 골인/관통 재도전을 확인한다.
판매 단계에서 기존 관통 터렛은 유지되고 별도 기본 터렛만 판매되어야 한다. 새 지점의 2→1 조합은 거대 터렛이어야 한다.
한글 설명/스킵 버튼이 네모로 표시되지 않는지와 해상도를 변경해도 설명 박스가 화면 밖으로 나가지 않는지 확인한다.
일반 웨이브 몬스터는 새 인스턴스를 사용하므로 기존 몬스터 풀의 초기화 문제를 수정하지 않는다.
기존에 편집한 경계벽/안개 배치는 유지한다. 실제 플레이에서 등장 위치의 높이와 NavMesh 경로, 화면 밖 방향 안내, 건설/조합 후 안내 종료를 확인한다.
