## 막힌(버그 발생한) 부분

1. Main 브랜치에 문서 정리 중으로 작업 중인 브랜치에서는 확인이 안되는 상황


2. 팀원간 연관된 작업을 진행할 때 작업물 중복되는 경우 처리 방식 (팀장님 안내)




## 해결방안

1. 팀원 의견 조합 결과 깃허브에서 메인 브랜치 이동하여 확인 하는데 번거로움이 없다고 하여 현 상황 유지.

2. 개발 명세서 기준이 되는 팀원의 작업물을 메인 작업물로 선정하는 것이 우선이고, 개발 명세서를 통해서도 확인이 어려운 중복 작업물은 기능의 책임이 더 큰 쪽이 메인 작업물로 선정한다.

### 추가 내용

중복 작업물에 대한 처리 방식은 `Ground Rule`의 '소통규칙'의 '작업이 막혔을때' 하단에 보완하여 작성한다.
