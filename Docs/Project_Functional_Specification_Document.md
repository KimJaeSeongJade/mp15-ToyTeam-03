# 프로젝트 기능명세서

1. 프로젝트 정보 

장르 : 타워 디펜스, TPS (+여유시 추가 기능 구현)


2. 컨셉 

참고링크

일정시간마다 소환되는 몬스터 웨이브를 방어하는 타워 디펜스 게임.
타워를 건설할 때 플레이어가 직접 움직여서 타워를 건설해야함.

플레이어는 타워 건설이외에 직접 몬스터를 상대할 수있다. 


3. 기술환경 

사용 언어 : C#
Unity 버전 : 2022.3.62f
타겟 플랫폼 : Windows
외부 패키지 : ex : DOTWEEN
Input 방법 : Input System
Graphic 파이프라인 : URP



4. 핵심매커니즘과 담당 

    1. 타워 건설 시 이미 건설된 타워가 있다면 업그레이드 되는데 추가로 건설될 타워의 종류에 따라 다른 타워가 건설된다.
    2. 대공 타워와 대지 타워로 구분된다.
    3. 타워는 정해진 위치에 설치할 수 있다.
    4. 몬스터는 NavMesh, 정해진 경로로 몬스터가 이동한다.
    5. 이동만하는 몬스터와 타워를 공격하는 몬스터가 있다.
